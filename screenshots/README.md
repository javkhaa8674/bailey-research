## Analysis Rules

Use the following timeframe hierarchy:

**D1 → H4 → H1 → M5**

Use Bailey's framework:

**HTF Market Context
→ Current Trading Leg
→ Relevant Liquidity
→ POI
→ Liquidity Interaction
→ M5 CHoC
→ M5 Imbalance
→ Entry**

Do not treat ordinary support/resistance as a Bailey POI unless the market structure supports it.

Do not assume a liquidity level is "Relevant Liquidity" merely because it is the nearest high/low.

# Required Output

For each asset determine:

1. HTF Market Context
2. Current Trading Leg
3. Relevant Liquidity
4. Why that liquidity is relevant
5. POI
6. Long scenario
7. Short scenario
8. Preferred bias
9. M5 confirmation required
10. Invalidation
11. Which asset has the cleanest Bailey setup

Do not force a trade when the required sequence is incomplete.

Final classification:

**LONG / SHORT / WAIT / NO TRADE**
